# Problem

Core claim: Designing an incentive-compatible auction that maximizes the auctioneer's expected revenue is a central open problem; even the two-bidder two-item case is unsolved after four decades.

Supporting detail: Recent deep-learning auction designers only handle a fixed set of bidders/items or force the auction to be symmetric, ignoring the rich public context of real markets.

Narration: A classic problem in auction theory is designing a mechanism that maximizes the seller's revenue while staying incentive-compatible. Myerson solved the single-item case in 1981, but the multi-item case remains open, and prior deep methods assume fixed or symmetric auctions.
