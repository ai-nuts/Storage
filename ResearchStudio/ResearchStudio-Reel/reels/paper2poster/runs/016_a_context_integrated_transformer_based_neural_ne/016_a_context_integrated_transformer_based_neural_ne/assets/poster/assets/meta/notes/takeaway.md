# Takeaway

Core claim: By folding public context into a permutation-equivariant transformer, CITransNet learns near-optimal, asymmetric, incentive-compatible auctions and, because its size is scale-independent, generalizes to auctions with more bidders or items than it was trained on.

Supporting detail: It is the first neural auction designer to combine contextual features, asymmetric mechanisms, and out-of-setting generalization in one architecture.

Narration: The takeaway: context as a first-class input unlocks better learned auctions. CITransNet is near-optimal, asymmetric when needed, and incentive-compatible. Its size-independent parameter count lets one trained model transfer to auction sizes it never saw.
