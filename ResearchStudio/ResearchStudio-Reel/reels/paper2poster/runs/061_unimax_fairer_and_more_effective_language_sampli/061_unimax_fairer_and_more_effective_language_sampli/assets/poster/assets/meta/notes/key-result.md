# Key Result

Core claim: UniMax consistently outperforms τ=1 and τ=3.33 on average TyDi QA across all three model sizes, and outperforms temperature sampling on WMT21 across all scales, with the majority of language pairs benefiting.

Supporting detail: On high-resource TyDi languages UniMax beats τ=3.33 and only trails τ=1 at the largest scale; it wins on low-resource languages, e.g. outperforming τ=3.33 on Swahili despite seeing fewer Swahili examples.
