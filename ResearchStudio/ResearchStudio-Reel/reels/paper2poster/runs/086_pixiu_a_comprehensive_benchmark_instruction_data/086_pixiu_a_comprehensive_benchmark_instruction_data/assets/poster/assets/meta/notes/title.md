# Title

This is PIXIU, a comprehensive open-source framework for financial artificial intelligence, published at NeurIPS 2023. Financial language is highly technical, yet before PIXIU there were no openly released financial large language models, no financial instruction tuning data, and no holistic evaluation benchmark. PIXIU fills all three gaps at once. It contributes FIT, the first multi-task, multi-modal financial instruction dataset with one hundred and thirty-six thousand samples; FinMA, the first openly released instruction-following financial large language model built by fine-tuning LLaMA; and FLARE, a standardized benchmark spanning financial natural language tasks and stock movement prediction. Together they let the community build, compare, and advance financial LLMs in the open.
