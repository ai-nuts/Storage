# Problem

Core claim: Deep learning attains high accuracy but relies on massive data, supervised or reward-based rules, and heavy energy, and it suffers catastrophic forgetting — unlike living systems that learn and adapt from sparse data with little energy.

Supporting detail: Hopfield networks offer unsupervised, associative, one-shot learning, yet basic implementations store only about 0.14N patterns and few extensions draw on biologically-inspired mechanisms.

Narration: A large part of recent AI progress comes from deep learning paired with big data, trained by supervised or reinforcement signals. These systems are powerful, but they behave very differently from living systems, which learn, make associations, and adapt using sparse data, efficient energy use, and few training iterations. They also forget previous tasks when trained sequentially, a problem known as catastrophic forgetting. Hopfield networks, with unsupervised learning and an associative memory, offer a more biologically plausible alternative, but their simplest forms are limited, storing only about zero point one four times the number of nodes in patterns, and rarely exploit the biological mechanisms that inspired them.
