# Headline Numbers

Core claim: Hopfield networks store approximately 0.14N patterns, where N is the number of nodes — the capacity limit that motivates the paper's biologically-inspired extensions.

Supporting detail: The paper draws on a broad literature (roughly 67 references spanning neuroscience, molecular biology, and machine learning) but reports no experimental metrics of its own.

Narration: The one quantitative anchor in this paper is the classic capacity limit of a standard Hopfield network: it can reliably store only about zero point one four times the number of nodes in the network in distinct memory patterns. This ceiling is a key reason the paper looks to biological mechanisms to extend the network's capabilities. Beyond that figure, the work reports no experimental numbers, because it is a conceptual proposal that synthesizes ideas across neuroscience, molecular biology, and machine learning rather than measuring a system.
