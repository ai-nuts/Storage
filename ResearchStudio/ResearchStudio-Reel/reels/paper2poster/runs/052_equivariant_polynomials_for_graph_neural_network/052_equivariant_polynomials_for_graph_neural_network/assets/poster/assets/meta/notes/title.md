# Title

Graph neural networks are limited in what they can compute, and the yardstick, the Weisfeiler-Lehman hierarchy, is hard to interpret and too coarse to separate architectures. This ICML 2023 paper measures a graph network instead by which equivariant polynomials it can compute. The authors give a complete basis for these polynomials, build tools to read off any model's exact power, and design a stronger network that reaches state of the art on molecular benchmarks.
