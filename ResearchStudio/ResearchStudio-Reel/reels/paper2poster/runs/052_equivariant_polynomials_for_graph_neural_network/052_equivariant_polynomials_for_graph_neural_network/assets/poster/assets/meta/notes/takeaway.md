# Takeaway

Core claim: Grading and building graph networks by the equivariant polynomials they can compute, each a multi-graph evaluated as a tensor contraction, yields a finer expressiveness hierarchy than WL and, in practice, precomputed polynomial features push standard GNNs beyond 3-WL and to state-of-the-art accuracy on molecular benchmarks.

Supporting detail: The basis plus the linear-time computability algorithm turn "how expressive is this GNN?" into a concrete, checkable question with an actionable answer.

Narration: The lasting message: express a network's power as which equivariant graph polynomials it can compute. Each is a small multi-graph evaluated by a tensor contraction, a finer ruler than Weisfeiler-Lehman and a direct list of missing operations. Acting on that list, precomputed polynomial features push ordinary graph networks past three-WL to best-in-class molecular property prediction.
