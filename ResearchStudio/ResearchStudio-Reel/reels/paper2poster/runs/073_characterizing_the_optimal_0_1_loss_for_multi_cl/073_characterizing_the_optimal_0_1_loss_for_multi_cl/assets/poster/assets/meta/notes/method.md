# Method

Core claim: For a discrete distribution, build a conflict hypergraph whose vertices are data points and whose hyperedges connect same-neighborhood examples from different classes. The optimal robust loss is then a linear program over achievable correct-classification probabilities; its dual is a fractional covering of vertices by hyperedges that yields the adversarial strategy.

Supporting detail: To scale, the hypergraph is truncated to a maximum hyperedge degree m (giving lower bounds L(m)), binary 1-vs-1 optimal losses are aggregated via maximum-weight coupling (a looser but cheap lower bound L_CO(2)), and a generalized Caro-Wei bound on the independent-set number gives an upper bound L_CW.

Narration: The core idea is to represent the classification problem as a conflict hypergraph. Each vertex is a data point, and a set of points forms a hyperedge when they belong to different classes yet share overlapping adversarial neighborhoods, meaning an attacker could push any of them to the same confusing input. The optimal 0-1 loss then becomes a linear program: maximize the probability mass of correctly classified points subject to constraints encoded by the hypergraph's incidence matrix. The dual program is a fractional covering of vertices by hyperedges, and it directly yields the optimal adversarial strategy. Because computing all hyperedges up to degree ten is infeasible, the authors truncate the hypergraph to lower degrees for tractable lower bounds, aggregate binary one-versus-one losses for an even cheaper bound, and apply a generalized Caro-Wei bound for a matching upper bound.
