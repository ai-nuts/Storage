# Contribution

Core claim: The paper introduces USIS10K, the first large-scale underwater salient instance segmentation dataset (10,632 images, pixel-level annotations, 7 categories), and USIS-SAM, a SAM-based architecture with an Underwater Adaptive ViT encoder and an automatic Salient Feature Prompt Generator.

Supporting detail: USIS-SAM achieves state-of-the-art results on both class-agnostic and multi-class underwater salient instance segmentation, and datasets and code are publicly released.

Narration: The paper makes three contributions. First, USIS10K, the first large-scale underwater salient instance segmentation dataset, with 10,632 pixel-level annotated images across seven categories. Second, USIS-SAM, an architecture built on SAM featuring an Underwater Adaptive Visual Transformer encoder and an out-of-the-box Salient Feature Prompt Generator that removes manual prompts. Third, extensive experiments show it beats state-of-the-art methods, with data and code released.
