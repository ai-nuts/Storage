# Takeaway

Core claim: By pairing the first large-scale underwater salient dataset (USIS10K) with a SAM adapted through underwater visual prompts and automatic salient prompting, USIS-SAM sets a new state of the art for segmenting salient objects underwater.

Supporting detail: Both the dataset and code are publicly released, giving the community a foundation for future underwater vision research.

Narration: The takeaway is simple. Adapting a foundation model to a hard new domain works best when you also give it the right data and let it prompt itself. By building USIS10K and teaching SAM to see underwater while generating its own salient prompts, USIS-SAM sets a new state of the art. With dataset and code released, it lays a foundation for underwater vision research.
