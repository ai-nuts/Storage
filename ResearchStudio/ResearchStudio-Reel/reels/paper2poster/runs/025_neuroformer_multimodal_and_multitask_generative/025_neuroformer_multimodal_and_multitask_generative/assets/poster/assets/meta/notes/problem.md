# Problem

Core claim: Modern systems-neuroscience experiments yield large-scale, multimodal, cellular-resolution spiking data whose scale and heterogeneity outstrip the classical analysis tools built for smaller, single-modality recordings.

Supporting detail: Experiments now co-acquire neuronal activity, visual stimuli, and behavior (eye position, body movement), but linking circuit dynamics to behavior across these modalities remains hard.

Narration: Modern neuroscience records thousands of neurons at cellular resolution, alongside visual stimuli and behavior. These datasets are large, multimodal, and messy, yet the field's traditional statistical tools were built for far smaller, single-modality recordings, leaving a widening data-analysis gap.
