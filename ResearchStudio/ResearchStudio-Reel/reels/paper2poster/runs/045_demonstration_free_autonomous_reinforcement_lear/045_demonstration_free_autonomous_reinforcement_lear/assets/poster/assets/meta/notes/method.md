# Method

Core claim: IBC alternates between a forward agent π_f pursuing the task and an auxiliary agent π_a that returns it toward target initial states; the auxiliary agent is conditionally activated only when the forward agent fails, so its intervention fades as an implicit curriculum. A bidirectional goal curriculum casts curriculum generation as a Wasserstein Barycenter problem over particles sampled from the replay buffer, solved by bipartite matching via Minimum Cost Maximum Flow, jointly proposing K forward and K auxiliary curriculum goals.

Supporting detail: The surrogate objective relaxes the original RL objective using a Lipschitz-continuity assumption on the goal-conditioned value function; a diversity constraint allows at most one state per past trajectory to be selected, and off-the-shelf SAC optimizes the policies. Specifying the target distribution ρ_tar(s) needs only ~10 samples (sometimes a single example) from ρ_0(s) and the evaluation goal, no demonstrations.

Narration: Here is how IBC works. During training the agent constantly alternates between two roles. The forward agent tries to accomplish the task. The auxiliary agent brings it back toward a set of target initial states so it can practice again. The key trick is that the auxiliary agent is activated only when the forward agent fails, so as the forward agent gets better, the auxiliary agent naturally steps in less and less. That is the implicit curriculum. On top of this sits the explicit, bidirectional goal curriculum. Rather than relying on demonstrations, IBC samples candidate states from its own replay buffer and frames curriculum generation as an optimal transport problem, specifically a Wasserstein Barycenter augmented with a value bias term. It solves the resulting bipartite matching with a Minimum Cost Maximum Flow algorithm, producing K intermediate goals for the forward agent and K for the auxiliary agent. A Lipschitz-continuity assumption lets the method relax the true objective into a tractable lower bound, and standard Soft Actor-Critic handles the policy updates. Remarkably, defining the target distribution needs only about ten sample states, and sometimes just one, rather than thousands of demonstration transitions.
