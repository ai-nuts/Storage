# Takeaway

Core claim: Finite-rank KRR, the model behind last-layer fine-tuning, admits sharp two-sided non-asymptotic test-error bounds that stay tight for any ridge, including ridgeless, giving a much more accurate certificate of generalization than earlier one-sided or asymptotic results.

Supporting detail: The improvement comes from analyzing the target in the eigenfunction (L²ρ) basis, decoupling spectrum from sampling noise.

Narration: The takeaway: finite-rank kernel ridge regression, behind last-layer fine-tuning, has sharp bounds, matching upper and lower, tight for any regularization including none. The key idea, working in the eigenfunction basis to separate spectrum from sampling noise, is a template others can borrow.
