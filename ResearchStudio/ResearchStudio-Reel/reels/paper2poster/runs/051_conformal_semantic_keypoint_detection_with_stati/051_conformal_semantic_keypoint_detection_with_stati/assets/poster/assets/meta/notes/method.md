# Method

Core claim: Inductive conformal prediction calibrates heatmap nonconformity scores on a calibration set to build per-keypoint prediction sets (balls or ellipses) with 1−ε coverage. These constraints define the nonconvex PURSE over SE(3); RANSAG samples keypoints, solves P3P/PnP, and averages accepted poses into an average pose. A semidefinite relaxation maximizes pose-to-PURSE distance to certify worst-case rotation and translation bounds.

Supporting detail: Two nonconformity designs — peak (scaled peak-to-true error) and covariance (Mahalanobis distance over top-J detections) — yield circular vs elliptical sets. The worst-case bound problem is nonconvex; its SDP relaxation is either exact or gives a valid upper bound.

Narration: The method has two stages. In conformal keypoint detection, a calibration set of labeled images gives nonconformity scores for the heatmap detector. Two designs are offered: a peak score, the scaled distance from the true keypoint to the most probable pixel, and a covariance score, a Mahalanobis distance over top detections, yielding circular and elliptical sets. Sorting the scores gives a threshold so each true keypoint lies in its set with probability one minus epsilon. In geometric uncertainty propagation, these sets become quadratic constraints on the pose, defining the Pose Uncertainty Set. Since it is nonconvex, RANSAG samples three keypoints, solves the minimal P3P problem, keeps poses inside the set, and averages them. Finally, maximizing the distance to the farthest pose still inside PURSE, relaxed as a semidefinite program, certifies worst-case rotation and translation bounds.
