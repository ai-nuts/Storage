# Takeaway

Core claim: No current deep learning model reliably predicts antibody fitness across all developability properties, so much more work is needed before these models can dependably filter therapeutic antibody candidates.

Supporting detail: Intrinsic biophysical properties are captured far better than extrinsic ones, and promising paths forward include adding structure, antigen context, and physics-based priors.

Narration: The takeaway is honest and useful: no current deep learning model reliably predicts antibody fitness across all developability properties, so we are not yet at the point of trusting these models to filter therapeutic candidates on their own. The good news is that intrinsic properties are already captured reasonably well, which points toward the hardest remaining challenges. The authors argue the most promising path forward is to enrich these models with structural information, antigen context, and physics-based priors, and to keep growing open antibody fitness datasets like FLAb.
