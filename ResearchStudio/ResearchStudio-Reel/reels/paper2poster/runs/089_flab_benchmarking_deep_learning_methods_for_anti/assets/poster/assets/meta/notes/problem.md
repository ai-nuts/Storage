# Problem

Core claim: Existing protein fitness benchmarks (CAFA, TAPE, FLIP) either exclude antibody data or use very little of it, so there is no systematic way to evaluate how well deep learning models capture therapeutic antibody fitness.

Supporting detail: Antibody design methods are still judged by weak proxies like native sequence recovery, which do not indicate real therapeutic potential.

Narration: Machine learning can only speed up antibody design if models truly understand what makes an antibody good. Yet the major protein fitness benchmarks, like CAFA, TAPE, and FLIP, either leave antibody data out entirely or include only a sliver of it. That leaves researchers with no principled way to check whether a deep learning model actually captures antibody fitness. Today the field often falls back on weak proxies such as native sequence recovery, which say little about real therapeutic potential.
