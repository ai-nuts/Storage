# Method

Core claim: TimeSiam randomly samples a past subseries and a current subseries ("Siamese subseries") from the same time series, masks the current one via simple augmentation, and uses shared-weight Siamese encoders plus a cross-attention decoder to reconstruct the masked current series from the past observation. This past-to-current reconstruction forces the model to learn intrinsic temporal correlations.

Supporting detail: Learnable lineage embeddings, indexed by the relative distance between past and current subseries, are added to the encoded representation so one model can capture correlations across different time distances; at fine-tuning these lineages are averaged (fixed input) or concatenated per segment (extended input).

Narration: Here is how TimeSiam works. From a single time series it randomly samples two windows: a past subseries and a current subseries, together called Siamese subseries. The current window is lightly corrupted with a simple augmentation such as masking. Two shared-weight Siamese encoders process the past and current windows, and a decoder with cross-attention reconstructs the masked current series using the past observation as context. That single design choice, reconstructing the current from the past, forces the model to internalize how distant moments in a series relate. To handle the fact that past and current windows can be near or far apart in time, TimeSiam adds learnable lineage embeddings indexed by that relative distance, so one model fluently represents many temporal gaps. The training objective is simply the squared reconstruction error between the true and predicted current series.
