# Headline Numbers

Core claim: 8.6× memory efficiency, 2.0× training-time acceleration, and 1.6× inference-energy efficiency versus a leading spiking Transformer.

Supporting detail: 73.2% ImageNet-1K top-1 accuracy; O(L) training memory and O(1) inference cost; 85.7 MB/img training memory at 2.8 mJ inference energy.

Narration: To summarize the numbers that matter most: against a leading spiking Transformer at comparable accuracy, T-RevSNN delivers 8.6 times better memory efficiency, 2 times faster training, and 1.6 times lower inference energy. It reaches 73.2 percent top-1 accuracy on ImageNet-1K, using just 85.7 megabytes of memory per image and 2.8 millijoules per inference. And it achieves all of this with order L training memory and order one inference cost.
