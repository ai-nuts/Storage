Figure 1. Illustration of the temporal forward of vanilla SNN and T-RevSNN. (a) Vanilla SNNs unfold along the temporal, reusing all
parameters at each timestep. All spiking neurons accomplish the temporal dynamics. In the image classification task, images are input
repeatedly. Thus, the memory and inference costs of vanilla SNNs are O(L × T ) and O(T ), respectively. (b) In T-RevSNN, we only
allow the key spiking neurons (red spiking neurons in the figure) to pass temporal information. Coupled with the multi-level temporal
reversible design, the memory cost of T-RevSNN is O(L). Moreover, the image is encoded only once. The encoded features are divided
into T groups, exploited as input for each timestep. Correspondingly, the entire SNN is also divided into T independent sub-networks,
which only share parameters and transfer temporal information at key spiking neurons. Thus, the inference of T-RevSNN is O(1).
