# Method

Core claim: NubOT decomposes unbalanced OT into a mass-rescaling subproblem and a balanced feature-transport subproblem. It seeks reweighting fields η, ζ and forward/backward Monge maps T, S such that the rescaled proxy measures μ̃ = η·μ and ν̃ = ζ·ν are balanced and matched. Maps are learned as gradients of ICNN convex potentials (T = ∇g, S = ∇f); an alternating scheme updates η, ζ via unbalanced-Sinkhorn scaling and updates the potentials by min–max optimization.

Supporting detail: The reweighting functions are fit as neural networks so mass changes can be predicted for new cells; from the learned components the original semi-couplings (γ₁, γ₂) can be recovered exactly. Cycle-consistency ties the forward and backward maps together.

Narration: NubOT's key idea is to split the hard unbalanced problem into two coupled pieces: feature transformation and mass rescaling. It introduces proxy measures that are simply rescaled versions of the source and target, weighted by scalar fields eta and zeta, chosen so the two proxies have equal mass. Between these now-balanced measures it solves a standard optimal transport problem, learning forward and backward Monge maps as the gradients of convex potentials represented by input convex neural networks. Because the marginals themselves shift as the reweighting functions update, NubOT uses an alternating minimization: it estimates the mass rescaling with an efficient single-step unbalanced Sinkhorn update, then updates the transport potentials through a min-max objective, cycling between the two. The reweighting functions are learned as neural networks, so at test time the model can map a new cell and simultaneously predict whether its mass should grow or shrink.
