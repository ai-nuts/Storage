# Dataset / Benchmark

Core claim: A custom test suite of composite tasks pairing simple building-block tasks. Linguistic tasks include Capitalization, Swap, and translation tasks (Phrase Recombination with Longer Chain; Passive-to-Active with Object-to-Subject). Logical tasks include arithmetic operations (Two Sum, Modular, Plus One) composed with word-level ones.

Supporting detail: Tasks are grouped into separable composites (e.g., Capitalization & Plus One) versus compose-by-step composites (e.g., Capitalization & Swap, Modular & Two Sum Plus). Exact-match accuracy is used for logical tasks; word error rate (WER) for translation tasks.

Narration: The suite pairs simple building blocks. Linguistic tasks include capitalization, swapping, and translations like phrase recombination and passive-to-active. Logical tasks combine arithmetic with word operations. Tasks split into separable composites, acting on different input parts, and compose-by-step composites requiring chained reasoning.
