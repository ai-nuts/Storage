# Method

Core claim: Both tests convert subgraph counts into a vector of statistics (graph moments, i.e. injective-homomorphism subgraph densities, versus graph cumulants) and measure the difference between two samples with the squared Mahalanobis distance using analytically computed covariance matrices. Graph cumulants are obtained from graph moments through a combinatorial Möbius transform over partitions of a subgraph's edges that respects connectivity, quantifying the "excess propensity" of a substructure beyond what smaller substructures predict.

Supporting detail: The authors use connected subgraphs with at most r = 3 edges; computing the covariances requires counting connected subgraphs with up to 2r edges, giving both tests the same complexity, dominated by O(n^ω) matrix operations. Significance is computed analytically, with no sampling from inferred models.

Narration: Both tests follow the same three-step recipe: choose a maximum subgraph order, estimate each sample's distribution from its subgraph statistics, and measure the distance between the two estimates. That distance is the squared Mahalanobis distance, which weights differences by an analytically computed covariance matrix. The only difference between the tests is the coordinates: raw graph moments, which are injective-homomorphism subgraph densities, versus graph cumulants. Cumulants are obtained from moments by a combinatorial Möbius transform over all connectivity-respecting partitions of a subgraph's edges, capturing the excess propensity of a structure beyond what its smaller pieces already predict. Because computing the covariances only needs subgraph counts up to twice the chosen order, both tests share the same computational complexity.
