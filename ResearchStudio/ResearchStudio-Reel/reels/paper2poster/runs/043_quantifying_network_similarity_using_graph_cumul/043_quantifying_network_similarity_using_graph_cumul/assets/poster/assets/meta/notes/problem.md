# Problem

Core claim: Given two samples of graphs drawn i.i.d. from unknown distributions, decide whether the two distributions differ, using only statistics of their exchangeable, unlabeled edges.

Supporting detail: Nodes are indistinguishable, so tests cannot exploit a node-to-node correspondence; only subgraph-count statistics of pairwise interactions are available.

Narration: Suppose you are handed two collections of networks, each sampled from some unknown distribution, and asked a deceptively simple question: were they generated by the same process or by different ones? The nodes carry no shared labels, so you cannot match them one to one; all you can use are the statistics of their edges. This is the two-sample testing problem for networks, and it underlies tasks from comparing brain connectomes to distinguishing biological interaction networks.
