# Takeaway

Core claim: SiT is the first trajectory dataset recorded by a robot moving through real crowds with fully synchronized multi-modal sensors, semantic maps, and a unified perception-to-prediction benchmark, giving social navigation research the close human-robot interaction data that driving and fixed-camera datasets lack.

Supporting detail: Everything, including the development kit and trained baselines, is publicly available.

Narration: The takeaway is simple. If you want to build robots that move safely and gracefully among people, you need training data that shows the robot up close in the crowd, with all its sensors aligned in time and with the surrounding scene captured as a map. SiT is the first dataset to deliver that combination, together with a benchmark that spans detection, tracking, prediction, and end-to-end forecasting, and it is all publicly released so the community can build on it.
