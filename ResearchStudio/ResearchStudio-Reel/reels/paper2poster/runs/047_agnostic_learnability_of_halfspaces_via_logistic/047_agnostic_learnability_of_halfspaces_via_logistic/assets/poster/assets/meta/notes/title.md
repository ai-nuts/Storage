# Title

This paper asks a fundamental question in learning theory: how well does plain logistic regression solve the problem of agnostically learning halfspaces? A halfspace is a linear classifier, and in the agnostic setting an adversary corrupts an OPT fraction of the labels, so the best any linear classifier can do is a zero-one error of OPT. Prior work left a wide gap: a lower bound saying no convex surrogate can beat order OPT, and an upper bound showing logistic regression achieves only order square-root of OPT. The authors close this gap. They construct a well-behaved distribution on which the global minimizer of the logistic risk provably suffers square-root OPT error, matching the known upper bound exactly. They then show that adding a natural radial-Lipschitzness assumption lets logistic regression reach near-optimal order-OPT error. Finally, they give a strikingly simple two-phase algorithm, logistic regression followed by a perceptron step, that attains near-optimal error for any well-behaved distribution, replacing the many rounds of optimization that prior methods required.
