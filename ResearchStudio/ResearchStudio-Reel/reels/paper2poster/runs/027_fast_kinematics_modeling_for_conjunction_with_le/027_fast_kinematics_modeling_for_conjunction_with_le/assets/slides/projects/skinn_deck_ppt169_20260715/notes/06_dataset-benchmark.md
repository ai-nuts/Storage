The training set is constructed entirely with JAM, the physics code SKiNN is meant to imitate. The authors created five thousand input-output pairs, using four thousand for training, five hundred for validation, and five hundred held out for testing. Each velocity image is 551 by 551 pixels, generated at higher resolution than real data. Creating a single image with JAM takes about fifteen seconds, which underscores why emulation is worthwhile. The network is implemented in PyTorch with PyTorch Lightning and trained on five Tesla P100 GPUs, each with sixteen gigabytes of memory, over roughly one day.
