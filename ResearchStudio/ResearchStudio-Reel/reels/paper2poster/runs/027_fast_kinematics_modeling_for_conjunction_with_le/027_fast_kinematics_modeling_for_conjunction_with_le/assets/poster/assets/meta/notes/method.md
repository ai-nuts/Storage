# Method

Core claim: SKiNN is a convolutional network Ψθ mapping an 8-dimensional galaxy-parameter vector to a d×d velocity-dispersion (vrms) image. It has 5 blocks, each with two 2D convolutional layers, upsampling, and ReLU, trained with mean-squared-error loss and the Adam optimizer on JAM-generated data.

Supporting detail: The 8 inputs describe a Power-law Elliptical Mass Distribution (PEMD) plus elliptical Sérsic light profile (6 shape parameters) together with inclination i and anisotropy β. Training data is built with GLEE + JAM; the final model has about 7.07 million trainable parameters.

Narration: SKiNN precalculates JAM for use in lensing applications. Formally, it is a function that maps an eight-dimensional vector of galaxy parameters into a d by d image of vrms, the quadratic sum of velocity dispersion and rotational velocity. The eight inputs describe a power-law elliptical mass distribution and an elliptical Sérsic light profile, plus the galaxy inclination and orbital anisotropy. The architecture consists of five blocks, each with two two-dimensional convolutional layers followed by an upsampling layer and a ReLU nonlinearity, for about seven million trainable parameters. It is trained by minimizing a standard mean-squared-error loss with the Adam optimizer, using a dataset generated by JAM through the GLEE software so the network learns to mimic the JAM procedure.
