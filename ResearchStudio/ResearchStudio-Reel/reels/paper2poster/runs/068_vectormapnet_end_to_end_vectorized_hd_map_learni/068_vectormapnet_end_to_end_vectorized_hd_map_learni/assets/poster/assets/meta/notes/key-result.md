# Key Result

Core claim: VectorMapNet sets a new state of the art, surpassing HDMapNet by 14.2 mAP on nuScenes and 14.6 mAP on Argoverse2; on nuScenes it improves camera-only by +17.9 mAP, LiDAR-only by +9.9 mAP, and fusion by +14.2 mAP over HDMapNet.

Supporting detail: With the two-stage fine-tuning strategy, the fusion model reaches 53.7 mAP on nuScenes (vs. HDMapNet's 31.0), and sensor fusion adds +4.3 mAP over camera-only and +11.2 mAP over LiDAR-only.

Narration: VectorMapNet sets a new state of the art. It beats HDMapNet by 14.2 mAP on nuScenes and 14.6 on Argoverse2. Gains hold across sensors: nearly eighteen points camera-only, about ten LiDAR-only, over fourteen with fusion. Two-stage fine-tuning pushes fusion to 53.7 mAP versus 31.0.
