# Method

Core claim: Each cell is modeled by TabUnit as a key-value pair: a fuse layer gates data-type information into the column-name vector, a linking layer weaves that column vector into each value token, and the concatenated cell vectors, prefixed by a [CLS] token, are refined by a Transformer encoder. A shallow LSTM decoder, conditioned on the [CLS] state and a free-form prompt, autoregressively generates the target, unifying pretraining and finetuning.

Supporting detail: Pretraining combines two objectives: multi-cell-masking (randomly masking whole cells and predicting their content via maximum log-likelihood) and contrastive learning over row-block anchors/positives/negatives. Finetuning reframes any task as predicting a masked target column with a task-specific prompt.

Narration: At UniTabE's heart is a module called TabUnit that handles one cell at a time. It treats each cell as a key-value pair: the column name is the key, the content the value. The name is embedded and mean-pooled, and a data-type embedding, marking numerical, categorical, or textual, is fused in through a gate, so a salary column is handled whether its values are numbers or words. A linking layer injects the column vector into each value token, so attention links values to their column. All cell vectors, plus a CLS token, pass through a Transformer encoder. A deliberately shallow LSTM decoder, guided by a free-form prompt like fill in missing value salary, generates the answer token by token. Keeping the decoder weak forces most knowledge into the reusable encoder. Pretraining mixes multi-cell masking and contrastive learning.
