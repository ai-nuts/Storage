# Method

Core claim: Context shift names the semantically meaningful upstream factors driving distribution shift, driven by three concepts: sample selection bias, adversarial perturbations, and non-stationarity. Three methods address it: (1) human intuition and expert knowledge to surface features on which models systematically fail, (2) dynamic benchmarking that evaluates models continually against a well-specified data-generation process to yield corroborated accuracy, and (3) clarifying a model's limitations via an explicit limitations section.

Supporting detail: Unlike distribution shift, which can be measured between two datasets, context shift can only be fully addressed by understanding the whole population's data distribution and how it changes over space and time; non-stationarity is a special case of sample selection bias over features and labels that may differ in the future.

Narration: Context refers to the semantically meaningful upstream factors that drive a distribution shift. Rather than fixating on the difference between two distributions, Groh asks researchers to reason about the three processes that generate that difference: sample selection bias, for example a new dataset drawn from a demographic absent from the old one; adversarial perturbations, imperceptible noise injections that change model behavior; and non-stationarity, where the world itself moves on, like smartphones after 2018 versus flip phones before 2010. Three methods follow. First, human intuition and expert knowledge can identify the semantically meaningful features on which models are likely to fail. Second, dynamic benchmarking replaces a single static test set with continual evaluation against a well-specified, quality-controlled data-generation process, producing corroborated accuracy, the distribution of scores across many benchmarks. Third, authors should clarify a model's limitations, explicitly stating the contexts in which performance is known and unknown.
