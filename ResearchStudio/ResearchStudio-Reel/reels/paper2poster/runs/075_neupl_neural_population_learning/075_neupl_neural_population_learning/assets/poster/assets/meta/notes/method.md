# Method

Core claim: A single network Πθ(·|o, σi) represents all policies, each conditioned on a meta-strategy σi drawn from an interaction graph Σ; policies are trained jointly by RL to best-respond to their assigned opponent mixtures, with a learned payoff estimator φω connecting the population to its empirical payoff matrix.

Supporting detail: Interaction graphs may be static (Σ fixed, recovering fictitious play) or adaptive (Σ ← F(U) from a meta-graph solver such as FPSRO-N, recovering PSRO-Nash); lower-triangular graphs yield the sequence of N-step best-responses, and identical rows σi = σj collapse to identical policies so the effective population size emerges automatically.

Narration: "Concretely, NeuPL trains one opponent-conditioned network. Each policy index i is paired with a meta-strategy vector sigma-i that says, as a probability distribution, which other policies it should play against. The network maximizes discounted return under a double expectation — first over the sampled opponent, then over the game dynamics induced by both policies. To optimize this by reinforcement learning, NeuPL jointly trains an opponent-conditioned action-value function, and additionally learns a payoff estimator that predicts the expected outcome of any policy pairing directly from the value function, so the full payoff matrix can be evaluated cheaply without replaying every matchup. The interaction graph that assigns opponents can be a fixed matrix — reproducing fictitious play — or adaptive, recomputed from the learned payoffs by a meta-graph solver, reproducing PSRO-Nash. Because the graph, not a handcrafted schedule, controls which objectives are active, the number of genuinely distinct policies grows on its own as the game demands."
