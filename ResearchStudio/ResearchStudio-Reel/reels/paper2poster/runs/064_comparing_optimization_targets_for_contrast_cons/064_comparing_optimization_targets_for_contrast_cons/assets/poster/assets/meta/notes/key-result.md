# Key Result

Core claim: MD-CCS attains an average cosine similarity of ≈0.63 with CCS probers, versus a CCS self-similarity of only 0.78 — far above chance (two random 1024-d unit vectors reach 0.63 with probability ≈10⁻²³⁷), establishing MD as a faithful proxy for CCS's optimization target.

Supporting detail: No other high-accuracy loss (MA, SMR, PCA) comes close to CCS in cosine similarity (averages 0.14–0.17), so the resemblance is specific to MD, not a generic byproduct of accuracy.

Narration: The headline: Midpoint-Displacement tuned to imitate CCS gives probe directions averaging cosine similarity about zero point six three to real CCS probes, while CCS agrees with itself only at zero point seven eight. Other accurate losses like PCA sit near zero point one five, so the resemblance is specific to Midpoint-Displacement.
