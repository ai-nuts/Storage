# Method

Core claim: The test compares pooled transition functions before and after a candidate change point t via a CUSUM-type statistic. To avoid heavy plug-in bias from ML estimators, the authors augment the naive estimator with a mean-zero correction term, yielding a doubly robust estimating function ψ that lets flexible models (neural nets, random forests, lasso) estimate the nuisance transition and state-action distributions.

Supporting detail: Sample splitting and cross-fitting normalize the statistic across candidate t and test functions h; a Gaussian multiplier bootstrap over Q samples approximates the null distribution to compute the p-value. Non-pathwise-differentiability from the CUSUM absolute value blocks the classical efficient-influence-function route, so the estimator is built directly from an outcome-regression plus propensity-score pair.

Narration: Here is how the test works. At each candidate change point, it compares the pooled transition dynamics before and after that time using a CUSUM-style statistic. Naively plugging modern machine-learning estimators into this comparison introduces heavy bias, so the authors add a mean-zero augmentation term, producing a doubly robust estimating function. That lets flexible models like neural networks and random forests estimate the transition and state-action distributions without spoiling the inference. Sample splitting and cross-fitting normalize the statistic across candidate points and test functions, and a Gaussian multiplier bootstrap approximates its null distribution to yield the final p-value. The maximum over time and test functions of the normalized, CUSUM-weighted statistic gives the test statistic gamma-hat.
